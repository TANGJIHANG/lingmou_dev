# data/ —— 数据目录（**整个目录不进 Git**）

## 约定

| 子目录 | 放什么 | 是否可重建 |
|---|---|---|
| `raw/` | 原始下载的数据，**只读，绝不修改** | 可重新下载 |
| `interim/` | 格式转换的中间产物 | 可由 raw 重建 |
| `processed/` | 训练直接消费的最终格式 | 可由 raw 重建 |

**`raw/` 只读**是硬规矩：所有清洗、裁剪、重标注都写到 `interim/` 或 `processed/`。
一旦污染了原始数据，你无法判断问题是出在数据还是出在代码上。

## 为什么不进 Git

数据集动辄数 GB，Git 不适合大二进制文件，且会永久留在提交历史里清不掉。
数据放团队共享盘 / 网盘，**在本目录下用一个 `DATA_SOURCES.md` 记录来源与校验值**：

```markdown
## <数据集名>
- 来源 URL：
- 下载日期：
- 许可条款：（竞赛使用是否允许 —— **截图留档**）
- 本地路径：
- SHA256：
```

> **许可截图留档不是形式主义**：答辩引用公开数据集时，评委可能追问使用许可。
