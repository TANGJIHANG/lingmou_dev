# docs/img/ —— 证据物图片

答辩和报告里最有说服力的东西都在这里：**能跑起来的截图**比任何文字都硬。

## 该往这里放什么

| 类别 | 例子 | 何时产生 |
|---|---|---|
| 环境证据 | `nvidia-smi` 输出、`env_check.py` 的 PASS 截图 | D0 ✅ |
| 训练证据 | loss 曲线、带检测框的可视化图 | D3–D4 |
| 部署证据 | 国产板卡上跑出框的实拍/截图 | 上板后 |
| 环境试验 | 温度箱内通电运行的照片 | 环境验证阶段 |
| 对比图 | 轻量化前后同图检测结果对照 | 轻量化阶段 |
| 演示录屏 | 星载过境 / 无人机巡查两套场景 | 交付前 |

## 纪律

1. **文件名带日期**：`20260923_env_check_pass.png`。
2. **截图要能看出上下文**：终端截图要包含命令行本身，不要只截结果。
3. **不要 P 图**。经过处理的对比图要注明处理方式。
4. **录屏放不进 Git**，走共享盘，在本目录用 `RECORDINGS.md` 记路径与日期。
